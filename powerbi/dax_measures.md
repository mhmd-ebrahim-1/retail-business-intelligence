# 🧮 DAX Measure Reference Library & Business Logic
**Project:** Retail Business Intelligence & Customer Analytics Platform

---

## 1. Core Financial & Volume Measures

### Total Sales
```dax
[Total Sales] = 
SUM ( fact_sales[sales] )
```
*Format: Currency (`$#,##0.00`)*

---

### Total Profit
```dax
[Total Profit] = 
SUM ( fact_sales[profit] )
```
*Format: Currency (`$#,##0.00`)*

---

### Profit Margin %
```dax
[Profit Margin %] = 
DIVIDE ( [Total Profit], [Total Sales], 0 )
```
*Format: Percentage (`0.00%`)*

---

### Total Quantity Sold
```dax
[Total Units Sold] = 
SUM ( fact_sales[quantity] )
```
*Format: Whole Number (`#,##0`)*

---

### Average Discount %
```dax
[Average Discount %] = 
AVERAGE ( fact_sales[discount] )
```
*Format: Percentage (`0.00%`)*

---

### Total Orders
```dax
[Total Orders] = 
DISTINCTCOUNT ( fact_sales[order_id] )
```
*Format: Whole Number (`#,##0`)*

---

### Total Customers
```dax
[Total Customers] = 
DISTINCTCOUNT ( fact_sales[customer_key] )
```
*Format: Whole Number (`#,##0`)*

---

### Average Order Value (AOV)
```dax
[Average Order Value] = 
DIVIDE ( [Total Sales], [Total Orders], 0 )
```
*Format: Currency (`$#,##0.00`)*

---

### Average Items per Order
```dax
[Avg Items Per Order] = 
DIVIDE ( [Total Units Sold], [Total Orders], 0 )
```
*Format: Decimal (`0.0`)*

## 2. Time Intelligence & Growth Calculations

### Prior Year Sales (PY)
```dax
[Sales PY] = 
CALCULATE (
    [Total Sales],
    SAMEPERIODLASTYEAR ( dim_date[full_date] )
)
```
*Format: Currency (`$#,##0.00`)*

---

### Sales YoY Growth ($)
```dax
[Sales YoY Growth $] = 
VAR CurrentSales = [Total Sales]
VAR PriorSales = [Sales PY]
RETURN
    IF ( NOT ISBLANK ( PriorSales ), CurrentSales - PriorSales, BLANK () )
```
*Format: Currency (`$#,##0.00`)*

---

### Sales YoY Growth %
```dax
[Sales YoY Growth %] = 
VAR CurrentSales = [Total Sales]
VAR PriorSales = [Sales PY]
RETURN
    DIVIDE ( CurrentSales - PriorSales, PriorSales, 0 )
```
*Format: Percentage (`+0.00%;-0.00%;0.00%`)*

---

### Prior Year Profit (PY)
```dax
[Profit PY] = 
CALCULATE (
    [Total Profit],
    SAMEPERIODLASTYEAR ( dim_date[full_date] )
)
```
*Format: Currency (`$#,##0.00`)*

---

### Profit YoY Growth %
```dax
[Profit YoY Growth %] = 
VAR CurrentProfit = [Total Profit]
VAR PriorProfit = [Profit PY]
RETURN
    DIVIDE ( CurrentProfit - PriorProfit, ABS ( PriorProfit ), 0 )
```
*Format: Percentage (`+0.00%;-0.00%;0.00%`)*

---

### Sales Year-to-Date (YTD)
```dax
[Sales YTD] = 
TOTALYTD ( [Total Sales], dim_date[full_date] )
```
*Format: Currency (`$#,##0.00`)*

---

### Profit Year-to-Date (YTD)
```dax
[Profit YTD] = 
TOTALYTD ( [Total Profit], dim_date[full_date] )
```
*Format: Currency (`$#,##0.00`)*

---

### Sales 3-Month Rolling Average
```dax
[Sales 3M Rolling Avg] = 
AVERAGEX (
    DATESINPERIOD (
        dim_date[full_date],
        LASTDATE ( dim_date[full_date] ),
        -3,
        MONTH
    ),
    [Total Sales]
)
```
*Format: Currency (`$#,##0.00`)*

## 3. Customer Intelligence & Segmentation DAX

### Repeat Customer Rate %
```dax
[Repeat Customer Rate %] = 
VAR TotalCust = [Total Customers]
VAR RepeatCust = 
    COUNTROWS (
        FILTER (
            VALUES ( dim_customer[customer_key] ),
            CALCULATE ( DISTINCTCOUNT ( fact_sales[order_id] ) ) > 1
        )
    )
RETURN
    DIVIDE ( RepeatCust, TotalCust, 0 )
```
*Format: Percentage (`0.00%`)*

---

### Revenue Generated by Champions Segment
```dax
[Champions Segment Revenue] = 
CALCULATE (
    [Total Sales],
    FILTER (
        dim_customer,
        dim_customer[total_spend] >= 3000 && dim_customer[total_orders] >= 8
    )
)
```
*Format: Currency (`$#,##0.00`)*

---

### Revenue at Churn Risk (LTV > $3,000 & Inactive > 180 Days)
```dax
[Revenue at Churn Risk] = 
VAR MaxCalendarDate = MAX ( dim_date[full_date] )
RETURN
    CALCULATE (
        [Total Sales],
        FILTER (
            dim_customer,
            dim_customer[total_spend] >= 3000 &&
            DATEDIFF ( dim_customer[last_order_date], MaxCalendarDate, DAY ) > 180
        )
    )
```
*Format: Currency (`$#,##0.00`)*

## 4. Operational & Fulfillment DAX

### Average Shipping Lead Time (Days)
```dax
[Average Shipping Days] = 
AVERAGE ( fact_sales[ship_days] )
```
*Format: Decimal (`0.0` Days)*

---

### Delayed Orders Count (> 5 Delivery Days)
```dax
[Delayed Orders Count] = 
CALCULATE (
    DISTINCTCOUNT ( fact_sales[order_id] ),
    fact_sales[ship_days] > 5
)
```
*Format: Whole Number (`#,##0`)*

---

### On-Time Delivery Fulfillment Rate %
```dax
[On-Time Delivery Rate %] = 
VAR TotalOrders = [Total Orders]
VAR OnTimeOrders = 
    CALCULATE (
        DISTINCTCOUNT ( fact_sales[order_id] ),
        fact_sales[ship_days] <= 5
    )
RETURN
    DIVIDE ( OnTimeOrders, TotalOrders, 0 )
```
*Format: Percentage (`0.00%`)*

## 5. Discount Impact & Profit Bleeder Detection

### Unprofitable Transactions Total Loss
```dax
[Total Loss from Negative Profit] = 
CALCULATE (
    SUM ( fact_sales[profit] ),
    fact_sales[profit] < 0
)
```
*Format: Currency (`$#,##0.00`)*

---

### Profit Bleeder Transactions Count
```dax
[Loss-Making Transactions Count] = 
CALCULATE (
    COUNTROWS ( fact_sales ),
    fact_sales[profit] < 0
)
```
*Format: Whole Number (`#,##0`)*

---

### Loss-Making Transaction Rate %
```dax
[% Transactions Losing Money] = 
DIVIDE ( [Loss-Making Transactions Count], COUNTROWS ( fact_sales ), 0 )
```
*Format: Percentage (`0.00%`)*
